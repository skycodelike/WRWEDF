# 🚀 WRWEDF — Web Components & UI Elements Library

A modern **HTML • CSS • JavaScript UI Component Collection** built for developers and beginners who want ready-to-use website sections and learning examples.

This project provides reusable website components like **Headers, Footers, Hero Sections, Effects, Animations, Login Pages, APIs, Blogs, and 3D Elements**.

Perfect for:
- Beginner learning and practice

---

# 📌 Project Overview

WRWEDF is designed as a **component-based frontend system** where common website parts are separated and loaded dynamically using JavaScript.

Main Features:

✅ Dynamic Header & Footer Loader  
✅ Blog Article Pages  
✅ Code Copy Button Functionality  
✅ Carousel Slider with Auto Scroll  
✅ Scroll Reveal Animations  
✅ Responsive Layout Structure  
✅ Beginner Friendly Folder System

# ⚙️ Core JavaScript Features

## Component Loader

Automatically loads reusable components:

- Header
- Footer

This allows you to reuse layout across multiple pages.

Benefits:

- Clean structure
- Easy maintenance
- Faster updates.

---

## Copy Code Button

Users can copy code snippets instantly.

Features:

- Clipboard API support.
- Button feedback animation.
- Disabled state after copy.

---

## Carousel Slider

Custom JavaScript carousel system:

- Auto scrolling every 5 seconds.
- Manual left/right navigation.
- Infinite looping cards.
- Smooth animation transitions.

---

## Header Scroll Behavior

Header automatically hides when the footer becomes visible.

Helps:

- Improve reading experience.
- Reduce UI distraction.

---

## Reveal Animation

Scroll-based animation using Intersection Observer.

Used for:

- Blog content.
- About sections.
- UI elements.
